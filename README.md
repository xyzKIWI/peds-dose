# 兒科藥物劑量速算

急診工作用的單檔網頁，輸入體重 / 年齡，自動算每個藥的 mg、mL、顆數。

**Live**：[https://xyzKIWI.github.io/peds-dose/](https://xyzKIWI.github.io/peds-dose/)

## 內容

- 50+ 個急診常用兒科藥物
- 多模式：⭐釘選 / 🤧URI / 🤢AGE / 🫀PALS / 🚨急救 / 鎮靜 / 抽搐 / 抗生素 / 退燒 / 水劑換算
- PALS 互動演算法（Cardiac Arrest / Tachy / Brady）+ 連結 AHA/AAP 2025 原圖
- Ketamine 完整 IV/IM × induction/sedation/analgesia
- 抗生素、止吐、Procaterol、Taita 點滴等多 form 合併卡

## 資料來源

- Lexicomp + Nelson + UpToDate（劑量基準）
- AHA/AAP 2025 PALS Guidelines (DOI 10.1161/CIR.0000000000001368)
- 高醫小兒藥物速算表 (初版) + 小兒常用藥丹

## ⚠️ Disclaimer

個人臨床速算工具，僅供醫師快速參考。**最終劑量以主治醫師臨床判斷為準**，藥碼與濃度請於開藥前再次核對。
